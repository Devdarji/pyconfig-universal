# Configuration Reference

This document describes all available configuration options.

## port

Server port number

**Details:**
- **Type:** integer (1000-65535)
- **Required:** No
- **Default:** `8000`

## debug

Enable debug mode

**Details:**
- **Type:** bool
- **Required:** No
- **Default:** `False`

## database_url

Database connection URL

**Details:**
- **Type:** url
- **Required:** Yes
